# Actividad-breve-tema-1-David-Ca-o-Li-bana
Yo haría un videojuego tipo rol, con 4 personajes con niveles y enemigos. Sería para ordenador y de lenguaje que usaría java.
Utilizaría los botones wasd, el click de ratón para usar las habilidades de los personajes, añadiría un sistema de vidas ( una barra de vida), los tipos de personajes (Atacante, Sanador, Tanque y Comandante), los diferentes niveles (donde se derrotaran los enemigos y la base de los personajes, donde se pueden mejorar y comprra objetos que aumentan las estadísticas temporalmente), los enemigos ( que al eliminarlos sueltan la puntos, los que se utilizan para mejorar o comprar objetos), y los objetos ( que se pueden comprar y recoger)
